# Agentic EduVerse · 已实现效果清单（路演素材）

> 依据：仓库实际代码扫描 —— **21 个页面路由 / 42 个 API 路由 / 20 张数据表 / 8 种界面语言**。
> 本文只列**代码里真实存在且已跑通验证**的能力，不含规划项。

---

## 一、产品定位（可直接用于封面）

**一个 AI 驱动的三方协同教育宇宙**：教师授课、学生学习、家长知情，共用同一套数据与同一条 AI 通道。

三个特征句：

- **三端同源**：教师 / 学生 / 家长三个门户，同一班级数据实时互通，不是三个独立系统。
- **AI 深度嵌入**：AI 学伴、AI 出题、AI 预习、AI 课堂分析、AI 家长报告，覆盖"课前—课中—课后—家长"完整链路。
- **零外部付费依赖可跑**：不依赖 Docker、不依赖 Redis、不依赖付费 AI Key，一台普通 Windows 电脑即可完整演示。

## 二、入口与身份体系

| 能力 | 已实现效果 |
|---|---|
| 角色门户首页 | 首页提供**老师 / 学生 / 家长**三张角色卡，可视化入口，点击进入对应门户 |
| 注册与登录 | 邮箱 + 密码注册登录；注册时**身份跟随入口自动预选**（从教师端入口进来默认注册教师） |
| 角色隔离 | 三个端口的页面与接口按角色严格隔离：学生访问教师端会被**带说明地**引导到对应入口，而不是静默跳回 |

| 会话安全 | 路由守卫 + 接口鉴权双保险；未登录访问受保护页面跳登录、访问接口返回 401 |

## 三、教师端

### 3.1 班级管理
- **创建班级**：班级名称 + 上课时间 + 课时（10–300 分钟）+ 可选加入密码；提交前做完整中文化校验（名称、时间完整性、可解析性、课时范围）
- **班级列表**：卡片式展示名下所有班级，含开播状态、学生人数
- **房间码**：每个班级自动生成 6 位房间码（字符集排除易混淆的 `0/1/I/O`），一键复制，大小写不敏感
- **开播状态**：教师进入课堂页面即开播，学生端可见

### 3.2 课堂页（教师）
- **音视频授课**：连接音视频房间、开启摄像头 / 麦克风 / 屏幕共享，本地画面实时预览
- **课堂录制**：一键开始 / 停止，录制期间显示计时、实时画面路数与在线人数
- **课堂教材**：上传教材文件，学生端**实时出现**（无需刷新）；支持刷新按钮与失败原因明示
- **共享白板**：教师可绘制，笔画实时同步到全体学生
- **虚拟教室**：以网格呈现所有参与者，含头像、姓名、举手状态
- **课堂聊天**：实时群聊，含未读气泡（移动端悬浮入口）
- **热力图**：一键显示学生情绪/参与热力分布
- **辅导队列**：展示举手学生数，逐个进入**一对一私密辅导房间**
- **课堂分析页**：课堂记录趋势图 + 平均测验成绩 + 情绪反馈分布
- **课前预习（AI）**：基于教材生成预习讲稿，可试听、可发布给学生、可导出
- **邀请家长**：从已入班学生中选人 + 填家长邮箱，生成邀请链接（24 小时有效、一次性）
- **测验管理**：创建测验、发起答题、查看提交与成绩
- **角色扮演**：创建沉浸式场景（多角色 + 公开目标 + **秘密任务**），分配角色给学生，控制开始/结束

### 3.3 其他教师页面
- **角色扮演列表**：只显示有权访问的真实课堂场景，卡片式进入
- **角色扮演场景页**：草稿编辑、状态流转（草稿→进行中→已结束）、学生角色分配、实时场景对话

## 四、学生端

### 4.1 学习主页
- **我的班级**：展示已加入的班级卡片，直播中班级可「进入教室」
- **加入班级**：输入 6 位房间码 +（如需要）加入密码；**大小写均可**，所见即所输，支持粘贴带空格/连字符的码
- **学习统计**：本周学习时长、正确率、薄弱知识点、金币余额
- **金币激励**：首次加入班级等行为即时发放金币并弹出奖励提示

### 4.2 课堂页（学生）
- **进入直播课堂**：与教师、同学同处一个教室
- **观看教师音视频**：可看、可听，并显示画面网格
- **共享白板**：实时看到教师板书
- **课堂教材**：实时看到教师上传的教材，可点击下载
- **情感反馈**：一键提交当下情绪，教师端实时收到
- **课堂聊天**：参与实时讨论
- **举手求助**：举手进入教师辅导队列

### 4.3 AI 学伴（核心亮点）
五个学科 tab：**通用辅导 / 数学 / 语文 / 英语 / 编程**

- **启发式答疑**：不是直接给答案，而是结构化输出「解答 + 引导问题 + 练习题 + 鼓励语」
- **练习题**：每轮回答附带选择题，含选项、答案与解析
- **会话隔离**：每个学伴**各自独立**的会话与历史，切走再切回完整恢复，互不串扰
- **历史会话**：侧栏可回看历史提问，一键还原当时的完整对话

### 4.4 翻译器（AI 学伴内第 6 个 tab）
- **17 种语言互译**：中文（简/繁）、英语、日语、韩语、法语、德语、西班牙语、俄语、葡萄牙语、意大利语、阿拉伯语、泰语、越南语、印尼语、土耳其语、荷兰语
- **自动检测源语言**，并显示「检测为 英语」这类判定徽章
- **一键互换**源/目标语言（互换时把译文放进输入框，方便反向核对）
- **一键复制译文**、必要时给出「译注」
- **最近 6 条翻译**，点一下即可还原
- **语言对本地记忆**，下次进来沿用上次选择
- 快捷键：`Ctrl/⌘ + Enter` 直接翻译

### 4.5 知识点关联讲解视频（路演强亮点）
- **每次提问，回答下方自动生成 5 个相关讲解视频**（封面 + 标题 + UP 主 + 时长）
- **点击卡片 → 新标签页跳转到视频网址**，学生即刻观看真人老师讲解
- **点右上角 X → 该条推荐消失**，可继续问下一个问题；下个问题生成全新列表，互不影响
- 知识点影响检索质量：模型同时产出检索关键词，且**标题命中知识点的结果自动前置**
- 服务端带 30 分钟缓存与限流，热门知识点不重复抓取

### 4.6 虚拟人物工坊
- **自由涂鸦**：Canvas 手绘画布，支持橡皮擦、清空
- **贴纸装饰**：帽子、眼镜等配件一键添加
- **一键保存**：虚拟人物保存并穿戴，用于课堂头像

## 五、家长端

- **孩子绑定**：粘贴教师发的邀请链接 / 邀请码完成绑定；一个家长可绑定多个孩子并随时切换查看
- **绑定安全**：邀请 24 小时有效、一次性使用、**必须用被邀请的邮箱登录**才能兑换
- **学习看板**：按周查看孩子的学习时长、出勤、测验表现、情绪趋势
- **AI 成长报告**：自动生成《本周学习成长报告》——本周优势、需要支持、家庭活动建议、给孩子的鼓励话
- **报告入口**：选择孩子与周次，一键生成可分享的成长报告页

## 六、音视频与录制（完整闭环）

| 环节 | 已实现效果 |
|---|---|
| 实时音视频 | 基于 LiveKit，教师推流、学生订阅，多人在线同一房间 |
| 画面预览 | 本地与远端画面都渲染为带姓名标签的画面格，自己推流自己可见 |
| 屏幕共享 | 教师可共享屏幕（含"屏幕共享"标签） |
| 课堂录制 | 教师端一键录制，**网格合成所有参与者画面**（封面裁剪 + 昵称标签），麦克风混音 |
| 录制容错 | 录制中每 20 秒心跳；切换/重挂载不丢失；离开课堂自动收尾保存；防止误刷新丢录像；异常中断自动置为失败，不会永久锁死该班级 |
| 录像回放 | 回放页支持**主课堂音视频 + 同步白板**双栏，视频支持拖拽 seek（HTTP Range） |
| 录制状态 | 面板实时显示录制时长、正在录制几路画面、在线人数 |
| 设备诊断 | 摄像头/麦克风打不开时，面板内给出**本机检测结果**：访问地址是否安全、浏览器是否提供接口、权限状态、识别到的设备数量，以及分步骤的自救指引 |
| 权限精确定位 | 区分「还没授权」「已被永久屏蔽」「设备被占用」「系统级拦截」四种情况，各自给出对应解法 |

## 七、平台与工程能力

### 7.1 全站多语言（8 种）
- **中文 / 英语 / 德语 / 法语 / 意大利语 / 俄语 / 西班牙语 / 日语**
- **一键切换，全站即时生效**：导航、按钮、表单、提示语、错误信息全部跟随
- **刷新不闪回**：语言存于 Cookie，服务端首屏直出目标语言，无闪烁、无 hydration 不一致
- **类型安全**：以中文为唯一真源，其余 7 份字典受类型约束——漏译或拼错会直接编译报错
- 切换器位置：主页、登录页、三个角色的仪表盘、AI 学伴页

### 7.2 实时通信
- **Socket.IO 数据通道**：白板、聊天、举手、情绪、测验状态、角色扮演、教材更新通知
- **短期票据握手**：连接前签发 60 秒有效的一次性签名票据（防重放），通过后才建立连接
- **进房二次鉴权**：教师校验班级归属、学生校验入班关系
- **在线状态**：按连接粒度统计在线用户，正确处理"同一人多标签页"
- **课堂会话**：教师进房自动创建/复用一节课的 Session 记录（出勤、消息、情绪都挂在它下面）

### 7.3 数据与安全
- **20 张数据表**：用户、班级、选课、课堂会话、情绪日志、消息、教材、测验、提交、AI 记忆、角色扮演场景与消息、出勤、奖励流水、白板事件、课堂文件、录像、一对一辅导、家长邀请、家长绑定
- **票据化权限**：音视频进房权限写进 JWT 声明（教师可推流、学生只订阅）
- **限流**：AI 与检索类接口按用户限流
- **一次性凭证**：邀请、Socket 票据均一次性消费

### 7.4 工程落地（能演示的关键）
- **Windows 本地全栈可跑**：不依赖 Docker、不依赖 WSL
- **音视频服务零容器化**：使用 LiveKit 官方 Windows 原生二进制，单节点内存模式，**不需要 Redis**
- **AI 免密钥**：接入环境自带的云端大模型通道（前端直连、流式），**无需申请和保管 API Key**
- **一键启动**：`start-dev.bat` 同时拉起三个服务（Web / 实时服务 / 音视频服务）
- **录制零外部依赖**：不依赖 Egress、不依赖对象存储，录像直接落本地磁盘并提供带 Range 的流式回放

## 九、建议演示动线（3 分钟版）

1. **首页**：三张角色卡 + 右上角切到德语，全站瞬间变德语 —— 展示国际化与三端结构
2. **学生端 AI 学伴**：问「什么是分数的意义？」→ 得到启发式解答 + 练习题 + **下方 5 个讲解视频** → 点第一个，新标签页打开真实讲解视频
3. **翻译 tab**：输入一句中文 → 直译成日语，展示「检测语言」徽章与一键复制
4. **教师端课堂**：开摄像头（画面立刻出现）→ 上传一份教材 → 切换到学生窗口，教材**无需刷新已出现**
5. **录制**：教师点「开始录制」，面板显示时长与画面路数 → 停止 → 在录像回放页播放，展示视频 + 同步白板
6. **家长端**：绑定孩子 → 一键生成《本周学习成长报告》，展示优势 / 待支持 / 家庭建议 / 鼓励话

## 十、尚待补齐（建议单独一页"下一步"）

诚实标注边界，路演时反而更可信：

- **学生目前为只订阅**：学生能看能听教师画面，但默认不能自己开摄像头/麦克风（可开启，属产品决策）
- **多端需 HTTPS**：局域网 IP 访问时浏览器不提供摄像头接口，跨设备演示需配 HTTPS
- **录制格式为 WebM**：非 MP4；且录制期间教师标签页需保持打开
- **视频检索为页面解析**：B 站改版需同步更新解析逻辑；内容过滤目前是保守黑名单，未做人工审核
- **视频推荐不落库**：属即时推荐，刷新或翻历史会话不会再出现
- **服务端 AI 通道未配置**：目前 AI 全部走免密钥云端通道；若接入自有模型，可扩展为双通道
- **多语言覆盖**：主路径（入口 + 三端首页 + AI 学伴 + 家长绑定）已完成，课堂页与部分对话框仍在补
