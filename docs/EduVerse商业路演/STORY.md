# STORY.md — Agentic EduVerse · Business Roadshow (English, B2–C1)

## Audience & Goal
Foreign judges at a startup roadshow. 5–8 minutes. Goal: show a **working product** (not a
concept) that connects teachers, students and parents in one AI-powered classroom, then show
the market is real and the business model is simple.

## Language rule
Simple, clear English (B2–C1). Short sentences. No jargon. Every number has a source.

## Key proof numbers (use across slides)
- 3 portals · 21 pages · 42 APIs · 20 database tables
- 8 interface languages, 17 translation languages
- 5 subject AI companions + 1 translator
- 5 video suggestions per answer, ~1 second to find them
- 0 paid API keys, 0 Docker, 0 Redis — runs on one laptop (live demo ready)
